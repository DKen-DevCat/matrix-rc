## 配線で気をつけること（調査でわかったもの）

- DRV8833 基板（Kitronik 5108）は nSLEEP 端子を High にしないとモーターが回らない。3.3V につなぐ
- WS2812B モジュールの電源は 3.5〜5.3V。3.3V ではなく電池から取る
- リポの JST コネクタは赤黒の向きがメーカーによって違う。つなぐ前にテスターで赤が＋であることを確かめる

### 初心者が迷いやすい点

**XIAO ESP32S3 Sense**
- スイッチサイエンス版と Amazon B0C69FFVHH には 7ピンのヘッダーが2本付いてくるが、はんだ付けはされていない。ブレッドボードに挿すには自分ではんだ付けする。Amazon B0DRNW6KMG ははんだ付け済み。
- XIAO に電池用のコネクタはない。裏面の **BAT+／BAT− パッド**に線をはんだ付けし、その先にピグテールを付ける。
- USB-C からの充電電流は 100mA（スイッチサイエンスの仕様）。1100mAh の電池だと満充電まで約11時間以上かかる（推定）。
- XIAO の BAT 入力は 4.2V（仕様）。1S リポ以外はつながない。

**リポ電池と極性**
- JST-PH の赤黒の向きは、メーカー間で統一されていない。EEMB のページにも「使用前に機器とコネクタの極性を確認」とある。はんだ付けや接続の前に、必ずテスターで電池の赤＝＋を確かめ、XIAO の BAT+ へ赤がつながることを確認する。逆に挿すとショートや故障につながる。
- 電池側のコネクタは **PHR-02（ハウジング側）**。秋月の「コネクター付コード 2P(A)」（105679）やスイッチサイエンス 2215 も同じハウジング側なので、**電池とは嵌合しない**。電池と嵌合するのは、Amazon セットの「オス」側か、秋月 B2B-PH-K-S（ポスト）。
- Amazon の互換品「オス」は純正 JST ではない。固い・緩いことがある。
- EEMB のページには保護回路（PCM）、UL1642、IEC62133-2 の記載があるが、**PSE の記載はない**。保管と充電は耐火のリポバッグなどで行うのが安全。

**N20 モーター**
- **「1000RPM」と「1000:1」は別物。** Amazon には「1000RPM（毎分回転数）」と書かれた高速モーターが多い。今回の高減速は「低 rpm（6V で 15〜30rpm 程度）」を選ぶ。走行用の 300rpm と取り違えないよう、届いたらラベルで確認する。
- Hailege 6V 15RPM のページには減速比が書かれていない。別の出品の仕様表（6V 300RPM＝1:50）から逆算して 1:1000 前後と推定した。比率を保証したいなら Pololu 1000:1（6255）を選ぶ。
- 6V 定格のモーターを 1S（3.7〜4.2V）で回すので、無負荷回転は表示の6〜7割程度になる（推定。300rpm 品なら約180〜210rpm）。机上試験には十分。
- 軸は 3mm の D カット、長さ10mm。Pololu 32×7mm ホイールと FEETECH ホイールはどちらも 3mm D 軸用で適合する。
- Pololu 989 ブラケットは 10×12mm のギアボックス部を挟む形。汎用の N20 も同じ断面なので取り付けられる。ただし減速比でギアボックスの長さが変わるので、挟む位置を合わせる。
- 汎用の N20 は端子がむき出しのものが多い。リード線をはんだ付けし、モーター端子間に 0.1µF を付けるとノイズ対策になる。

**DRV8833（Kitronik 5108）**
- 同梱品は基板1枚だけで、ピンヘッダーは付いていない（販売店ページの同梱内容から判断）。秋月のピンヘッダーを切ってはんだ付けする。
- 38×28mm と大きいので、ミニブレッドボードではなく EIC-801 にした。
- **nSLEEP 端子を High にしないとモーターが動かない**（DRV8833 の nSLEEP は内部でプルダウンされている）。GPIO で制御するか 3.3V につなぐ。
- 電源 Vcc は 2.7〜10.8V（仕様）なので、1S リポを直接つなげる。在庫が3個しかない点にも注意。

**MOSFET とダイオード（高減速モーターのローサイドスイッチ）**
- IRLU3410PBF は「IRL」系のロジックレベル品で、ピンのピッチは 2.29mm（秋月の仕様）。ブレッドボードには少しピンを広げて挿す。3.3V 駆動時のオン抵抗はデータシートで確認すること（ここでは確認していない）。
- 1N5819 はモーターと逆向き（並列）に入れるフライバックダイオード。帯のある側をモーターの＋側（電源側）に向ける。

**スライドスイッチ**
- 小型スライドスイッチは定格 0.5A が上限（SS-12D00-G5）。電池の主電源をこれで切り替えると、モーター2個の起動電流やロック時の電流には余裕がない。机上試作では問題になりにくいが、本番では定格の大きいスイッチを使うか、XIAO の電源だけを切るなど構成を見直すこと。

**WS2812B**
- 秋月のモジュールは電源電圧 3.5〜5.3V（仕様）。**3.3V ではなく電池（3.7〜4.2V）から給電**する。データ線には 330Ω を直列に入れる。

**その他**
- マイクロスイッチ SS-10GL13 の端子はラグ形で、ブレッドボードには挿せない。リード線をはんだ付けする。
- タミヤのボールキャスターは高さを 11〜35mm で調整できる。32mm ホイールなら車軸の高さは約16mm なので、組み立て後に車体が水平になる高さに合わせる。
- はんだは初心者が扱いやすい鉛入り（Sn60/Pb40）にした。換気し、作業後は手を洗う。鉛フリーにするなら秋月 [129524](https://akizukidenshi.com/catalog/g/g129524/)（520円）。
- USB-C ケーブルは Mac につなぐ前提で C-C にした。USB-A ポートにつなぐなら秋月 [117017](https://akizukidenshi.com/catalog/g/g117017/)（A-C 0.5m、100円）。
- ニッパーとワイヤーストリッパーは対象外として計上していない。持っていなければ別途必要。
- ユニバーサルプレートの代わりは、入荷を待つか、100円ショップのプラ板や MDF 板に穴を開けて使う。

#### LTE を機体に載せる進め方（決めてほしいこと 7 の決定を受けて）

難しさは段階で分かれる。1-b1 は「ソフトが主で、手を動かす部分は配線だけ」。1-b3 は、MicroCat.1U がそのまま載るなら「配置と筐体」、載らないなら「基板を作ってはんだ付けする」で、後者が本当の山。どちらも AI が肩代わりできる部分と、できない部分をはっきり分けておく。

| 段階 | やること | 難しさ | AI が肩代わりできる | 自分で手を動かす |
|---|---|---|---|---|
| 入手 | メカトラックス公式ストアで MicroCat.1U を 1 枚買う（上の表）。代理店への問い合わせは保険 | **低**（見つかった） | 購入前の確認事項の整理、資料（SIM7672 の AT コマンド集・メカトラックスの資料）の読み込み | 購入・SIM の契約 |
| 1-b1 | MicroCat.1U を 1-b1 用の大きめの台車に載せ、XIAO の D6/D7（UART）でつなぐ（必要なら RP2350B を UART の素通しにする）。機体→VPS の UDP と DTLS-PSK を通す | **中**。配線は UART 2 本＋電源＋GND。ファームウェアが作業の大半 | ファームウェア全部（下の「ファームウェアの作り方」）、RP2350B の素通しファーム、電源の計算、AT コマンドの手順、ログの読み解き | 配線、SIM の挿入、電波の実測（床置きで RSSI／到達率） |
| 1-b3 | MicroCat.1U をそのまま名刺サイズの下段に収める。収まらないか電源が足りないときだけ、SIM7672JP（LCC＋LGA、17.6×15.7mm）を載せる小基板を自作する | そのまま載るなら **中**（配置・筐体・放熱）。自作基板なら **高**（下の 4 点） | KiCad の回路図・部品配置・配線の作成とチェック、設計ガイドとの照合、BOM、ステンシル付きの基板発注データ | 配置と筐体の工作。自作基板ならはんだ付け（ホットプレートかホットエアでのリフロー）、テスターでの確認、2〜3 回の基板の作り直し |

**「初めてのハード開発には重い」の中身**は、自作基板に進んだ場合の次の 4 点。いずれも「できない」ではなく「回数とお金がかかる」種類の難しさで、MicroCat.1U がそのまま載れば 1 と 3 はなくなる。

1. **実装**：モジュールは LCC（側面の端子）＋LGA（裏面の端子）で、手はんだでは裏面に届かない。ホットプレート（数千円）とステンシル（基板と一緒に発注、数百円）でリフローする。ホビーでは一般的な手順で、失敗しても部品代（モジュール 1 個数千円）で済む。モジュールは最初から 2 個買う
2. **電源**：送信時に 1〜2A のバーストが出る。XIAO の 3.3V からは取れないので、電池（3.4〜4.3V）からモジュールへ直結し、すぐそばに 100µF 以上を置く。電池が 3.5V を切ると送信のたびにモジュールが落ちる（設計書①の警告 3.5V はこのためにも効く）
3. **アンテナ**：基板上にアンテナを設計せず、モジュールのアンテナ端子から短い 50Ω の線で u.FL コネクタへ出し、技適の認証条件（利得の上限）に合う FPC アンテナを買って貼る。これで基板側の高周波設計をほぼなくせる。91mm の筐体でグランドが足りず効率が落ちる問題（レビュー A-5）は残るので、1-b1 の評価ボードで床置きの実測をしてから筐体内の置き場所を決める
4. **技適の守り方**：工事設計認証はモジュール単体に付く。モジュールを改造せず、認証条件の範囲のアンテナを使えば、自作基板に載せても問題ない。設計ガイドに書かれた条件（アンテナ利得・電源）から外れない

**ファームウェアの作り方（1-b1）**：モジュールの中の TCP/UDP を AT コマンドで操る方式ではなく、**PPP でつなぐ**。ESP-IDF の `esp_modem` が Quectel／SIMCom 系の AT 手順と PPP を持っていて、つながった後は Wi-Fi のときと同じ UDP ソケットと mbedTLS の DTLS がそのまま使える。`lib/core`（判断ロジック）はハードに依存しないのでそのまま。変わるのは「Wi-Fi の接続」が「モジュールの起動＋PPP」になる部分だけ。Arduino のまま進めるなら Arduino を ESP-IDF のコンポーネントとして組む形になるので、1-b1 では ESP-IDF に寄せるのが素直。

**帯域の現実**：UART の速さが上限になる。921,600bps なら PPP の後で実効 700kbps 程度。いまの機体は映像（QVGA 9fps で 400〜700kbps）＋音声（16kHz 16bit PCM で 256kbps）なので、音声は 8kHz か圧縮に、映像は 5fps 程度に落とす。モジュールが 2〜3Mbps の UART に対応していれば上げる。USB で結ぶ道（ESP-IDF の `esp_modem_usb_dte`）もあるが、XIAO の USB は書き込みにも使うので後回し。

**代理店に聞くこと**（MicroCat.1U で足りないときの保険。問い合わせの下書きに使う）

- 個人（または個人事業）への販売の可否と、最小数量
- EG800AK-JP／SIM7672JP の評価ボード（EVB キット）の型番・価格・納期。モジュール単体の価格・納期
- ハードウェア設計ガイド、AT コマンド集、工事設計認証の条件（対応アンテナと利得の上限）の入手方法
- UART の最大速度と、PPP での利用可否
- 国内キャリア（docomo／KDDI／SoftBank の MVNO データ SIM）での接続実績。IMEI 登録などの手続きが要るか
- 推奨するアンテナ（FPC タイプ）の型番

**SIM**：国内 MVNO のデータ専用 SIM（docomo 網のものが帯域の相性で無難。SIM7672JP は docomo の相互接続性試験が完了している）。基板が届く前に契約しない。

**1-b1 の完成条件に足すこと**：床置きでの RSSI と到達率、300ms 停止の回数、UART の速さごとの映像 fps。これが 1-b3 の筐体とアンテナの配置を決める材料になる。
