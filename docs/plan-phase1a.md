## 配線で気をつけること（調査でわかったもの）

- DRV8833 基板（Kitronik 5108）は nSLEEP 端子を High にしないとモーターが回らない。3.3V につなぐ
- WS2812B モジュールの電源は 3.5〜5.3V。3.3V ではなく電池から取る
- リポの JST コネクタは赤黒の向きがメーカーによって違う。つなぐ前にテスターで赤が＋であることを確かめる

- スイッチサイエンス版と Amazon B0C69FFVHH には 7ピンのヘッダーが2本付いてくるが、はんだ付けはされていない。ブレッドボードに挿すには自分ではんだ付けする。Amazon B0DRNW6KMG ははんだ付け済み。
- XIAO に電池用のコネクタはない。裏面の **BAT+／BAT− パッド**に線をはんだ付けし、その先にピグテールを付ける。
- USB-C からの充電電流は 100mA（スイッチサイエンスの仕様）。1100mAh の電池だと満充電まで約11時間以上かかる（推定）。
- XIAO の BAT 入力は 4.2V（仕様）。1S リポ以外はつながない。

**リポ電池と極性**
- JST-PH の赤黒の向きは、メーカー間で統一されていない。EEMB のページにも「使用前に機器とコネクタの極性を確認」とある。はんだ付けや接続の前に、必ずテスターで電池の赤＝＋を確かめ、XIAO の BAT+ へ赤がつながることを確認する。逆に挿すとショートや故障につながる。
- 電池側のコネクタは **PHR-02（ハウジング側）**。秋月の「コネクター付コード 2P(A)」（105679）やスイッチサイエンス 2215 も同じハウジング側なので、**電池とは嵌合しない**。電池と嵌合するのは、Amazon セットの「オス」側か、秋月 B2B-PH-K-S（ポスト）。
- Amazon の互換品「オス」は純正 JST ではない。固い・緩いことがある。
- EEMB のページには保護回路（PCM）、UL1642、IEC62133-2 の記載があるが、**PSE の記載はない**。保管と充電は耐火のリポバッグなどで行うのが安全。

**N20 モーター**
- **「1000RPM」と「1000:1」は別物。** Amazon には「1000RPM（毎分回転数）」と書かれた高速モーターが多い。今回の高減速は「低 rpm（6V で 15〜30rpm 程度）」を選ぶ。走行用の 300rpm と取り違えないよう、届いたらラベルで確認する。
- Hailege 6V 15RPM のページには減速比が書かれていない。別の出品の仕様表（6V 300RPM＝1:50）から逆算して 1:1000 前後と推定した。比率を保証したいなら Pololu 1000:1（6255）を選ぶ。
- 6V 定格のモーターを 1S（3.7〜4.2V）で回すので、無負荷回転は表示の6〜7割程度になる（推定。300rpm 品なら約180〜210rpm）。机上試験には十分。
- 軸は 3mm の D カット、長さ10mm。Pololu 32×7mm ホイールと FEETECH ホイールはどちらも 3mm D 軸用で適合する。
- Pololu 989 ブラケットは 10×12mm のギアボックス部を挟む形。汎用の N20 も同じ断面なので取り付けられる。ただし減速比でギアボックスの長さが変わるので、挟む位置を合わせる。
- 汎用の N20 は端子がむき出しのものが多い。リード線をはんだ付けし、モーター端子間に 0.1µF を付けるとノイズ対策になる。

**DRV8833（Kitronik 5108）**
- 同梱品は基板1枚だけで、ピンヘッダーは付いていない（販売店ページの同梱内容から判断）。秋月のピンヘッダーを切ってはんだ付けする。
- 38×28mm と大きいので、ミニブレッドボードではなく EIC-801 にした。
- **nSLEEP 端子を High にしないとモーターが動かない**（DRV8833 の nSLEEP は内部でプルダウンされている）。GPIO で制御するか 3.3V につなぐ。
- 電源 Vcc は 2.7〜10.8V（仕様）なので、1S リポを直接つなげる。在庫が3個しかない点にも注意。

**MOSFET とダイオード（高減速モーターのローサイドスイッチ）**
- IRLU3410PBF は「IRL」系のロジックレベル品で、ピンのピッチは 2.29mm（秋月の仕様）。ブレッドボードには少しピンを広げて挿す。3.3V 駆動時のオン抵抗はデータシートで確認すること（ここでは確認していない）。
- 1N5819 はモーターと逆向き（並列）に入れるフライバックダイオード。帯のある側をモーターの＋側（電源側）に向ける。

**スライドスイッチ**
- 小型スライドスイッチは定格 0.5A が上限（SS-12D00-G5）。電池の主電源をこれで切り替えると、モーター2個の起動電流やロック時の電流には余裕がない。机上試作では問題になりにくいが、本番では定格の大きいスイッチを使うか、XIAO の電源だけを切るなど構成を見直すこと。

**WS2812B**
- 秋月のモジュールは電源電圧 3.5〜5.3V（仕様）。**3.3V ではなく電池（3.7〜4.2V）から給電**する。データ線には 330Ω を直列に入れる。

**その他**
- マイクロスイッチ SS-10GL13 の端子はラグ形で、ブレッドボードには挿せない。リード線をはんだ付けする。
- タミヤのボールキャスターは高さを 11〜35mm で調整できる。32mm ホイールなら車軸の高さは約16mm なので、組み立て後に車体が水平になる高さに合わせる。
- はんだは初心者が扱いやすい鉛入り（Sn60/Pb40）にした。換気し、作業後は手を洗う。鉛フリーにするなら秋月 [129524](https://akizukidenshi.com/catalog/g/g129524/)（520円）。
- USB-C ケーブルは Mac につなぐ前提で C-C にした。USB-A ポートにつなぐなら秋月 [117017](https://akizukidenshi.com/catalog/g/g117017/)（A-C 0.5m、100円）。
- ニッパーとワイヤーストリッパーは対象外として計上していない。持っていなければ別途必要。
- ユニバーサルプレートの代わりは、入荷を待つか、100円ショップのプラ板や MDF 板に穴を開けて使う。
