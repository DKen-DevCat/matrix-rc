# Fusion → 物理演算

Autodesk Fusion で組んだ機体を、`sim/` の物理演算に持ち込む手順。形状と質量は Fusion、ばね・モーター・摩擦は `sim/matrix_sim/params.py`（と実測値）から取る。

## Fusion 側の約束

1. **1 つのデザインに機体を全部入れる**（無料版のファイル数の上限対策にもなる）
2. **向きと原点**：x が前、y が左、z が上。原点は「車体の後端・左右の中心線・地面（タイヤの接地面）」
   - 初期設定の「Y が上」のままだと向きが合わない。基本設定の「既定のモデリング方向」を「Z 軸が上」にしてから作るか、組み立て全体を回転させる
3. **ばねは伸びきった状態**で組む（物理演算はそこを基準に縮める）
4. **コンポーネント名で役割を決める**

   | 名前 | 中身 |
   |---|---|
   | `upper_*`（例：`upper_deck`、`upper_battery`、`upper_xiao`） | 上段に載るもの。いくつに分けてもよい |
   | `lower_*`（例：`lower_deck`、`lower_motor_l`、`lower_cam`） | 下段に付くもの（車輪以外） |
   | `wheel_rl` `wheel_rr` `wheel_fl` `wheel_fr` | 車輪（後ろ左・後ろ右・前左・前右）。**4 つ別のコンポーネント**にする（同じものを 4 回置くと区別できない）。後ろ左が左モーター、後ろ右が右モーター |
   | それ以外 | 書き出さない（ねじなど。重さが効くなら `upper_`／`lower_` を付ける） |

   役割付きのコンポーネントの中にさらにコンポーネントがあれば、親ごと 1 つの部品として書き出す。
5. **上段・下段は中心線に対して左右対称に置く**（干渉の確認は幅の中心を中心線とみなす）
6. **密度の違う物は別のコンポーネントにする**：MuJoCo は 1 つの部品の中を密度一様として重心と慣性を計算する。金属のモーターと樹脂の板を 1 つにまとめると重心がずれる。レポートの「重心」の差が 2mm を超えたら分ける
7. **質量**：Fusion は材料の密度から計算する。電池や基板は「物理マテリアル」で密度を合わせるか、実物を量って合わせる（書き出した `parts.json` の `mass` を直接書き換えてもよい）

## 書き出し

1. Fusion の「ユーティリティ」→「アドイン」→「スクリプトとアドイン」を開く
2. 「+」→「既存のスクリプトを追加」で `sim/fusion/export_for_sim` フォルダを選ぶ
   - うまく読み込めないときは、「作成」で Python のスクリプト `export_for_sim` を新しく作り、中身を `export_for_sim.py` で置き換える
3. 実行して、書き出し先に `sim/fusion/export` を選ぶ → 部品ごとの STL と `parts.json` ができる

## 物理演算で使う

```sh
cd sim
make report ARGS="--parts fusion/export"      # 結果を Fusion の形で作り直す
make view ARGS="--parts fusion/export"        # 見る
```

書き出した `fusion/export/` はコミットしてよい（結果を再現できるように）。

## 確認していること・していないこと

- `fusion/sample/` は今の箱と円柱のモデルから作った見本で、読み込みの流れはこれでテストしている（`tests/test_parts.py`）
- **`export_for_sim.py` は Fusion の中でまだ動かしていない**（開発環境に Fusion がないため）。初回は書き出された `parts.json` の質量・外形が Fusion の表示と合っているかを見る
- STL の単位（mm／cm）は `parts.json` の外形と比べて自動で判定する
- 慣性は、部品ごとに密度が一様として MuJoCo がメッシュから計算する。Fusion は体（ボディ）ごとの材料で計算するので、1 つの部品に材料が混ざると差が出る。重心の差はレポートに出す（`parts.com_mismatch_mm`）。メッシュは閉じている必要がある
- 車輪の中心の高さが半径と 0.5mm 以上違うと読み込みを止める（原点が地面にないか、車輪が浮いている）
- 外形は `preciseBoundingBox`（ぴったりの外形）を使う
- 書き出した STL が組み立ての座標（ワールド座標）で出ることは、Fusion で初めて動かすときに確かめる
- 上段と下段は凸包（へこみを埋めた形）で衝突する。車輪は外形から作った円柱で衝突する
